# food-savers

Test automation repository for the Food Savers web application.

## Playwright MCP in VS Code

This repository configures the official Playwright MCP server in
`.vscode/mcp.json`. Install Node.js if it is not already available, then open
the repository in VS Code and accept the prompt to start the `playwright` MCP
server. If the prompt does not appear, open the MCP server list in Copilot Chat
and start `playwright` manually.

The server gives Copilot browser tools to open pages, inspect the UI, and
reproduce user flows. For example, ask Copilot to inspect the login page and
report the steps and visible validation messages. Do not put passwords or
other secrets in prompts.

MCP browser interaction is separate from the Python test suite: it does not
run pytest tests or automatically add test cases. Use the MCP browser to
explore and debug, then add or update Python tests under `tests/` and run them
from the repository root:

```powershell
.\venv\Scripts\python.exe -m pytest
```

The Playwright planner, generator, and healer agents generated by
`npx playwright init-agents --loop=vscode` target Playwright Test (JavaScript
or TypeScript), not this repository's Python `pytest-playwright` suite. This
setup intentionally adds MCP browser access without changing the existing
test stack.
