# food-savers
Test automation repository for web application.

## Steps to use this repository to run testcases
1. Install Python 3.12 or above and git in your system
2. Create a folder in your system and use the git clone command to clone this repo
3. Open the cloned folder in any IDE (VS Code prefferred).
4. Create a virtual environment and activate it (python -m venv venv,   venv\Scripts\activate)
5. Install the requirements (pip install -r requirements.txt)
6. Create a .venv file to inpute the username and passord.
7. Run tests using command: pytest

### Sample .env file
BASE_URL=https://foodsavers.app/
FS_USERNAME=abcd@gmail.com
FS_PASSWORD=Abcd@123
